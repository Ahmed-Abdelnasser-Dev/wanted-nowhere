# base Idea

Wanted Nowhere is a 2D top-down rogue-like game built in Godot Game engine and targeted for Desktop, web, Mobile. the game takes place in a fantasy world, you play as a vampire that is hunted by both humans and monsters and is in a constant fighting mode.

days and nights go by and you are still fighting, trying to avoid the sun in the day using the **shadow** and unlocking your full power at night.

the game also counts the moon cycles as you are stronger with the full moon.

as you are a vampire you are constantly healing from the combat and you build up exp which will show u cards that has upgrades you your stats or ability.

you have 4 abilities, dash, bat transform, AOE Ability and your Ultimate, you can use them using the QWER keys while u move and attack using the mouse keys.

the game has 2 types of enemies and some bosses for each one (Human, Monsters).

the game will be in both English and Arabic.
